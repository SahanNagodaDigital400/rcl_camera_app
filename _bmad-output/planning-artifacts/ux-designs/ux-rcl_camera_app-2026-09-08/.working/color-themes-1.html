Rocell Tile Scanner — Color Theme Options

Four palette-and-register directions for the internal staff PWA, each built from the same two real screens: a phone-width scan result and a desktop admin user-list row. Every theme uses all three brand colors — navy as chrome/primary, orange as the single accent/CTA color, red reserved strictly for destructive/deactivated states — over a different neutral base and register. Scroll horizontally to compare.

Light mode only — no dark theme in scope for this tool
